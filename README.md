# 桌面壁纸轮播

一个轻量的 Android 壁纸自动轮换工具：在 App 里添加壁纸，桌面就会按设定间隔自动轮换（只修改桌面壁纸，不碰锁屏）。解决了 ColorOS 只有锁屏轮播壁纸而没有桌面轮播壁纸的问题。

## 功能

- ✅ 添加壁纸：右下角 **+**，支持一次选最多 9 张（照片选择器）
- ✅ 自动轮换：1分钟 / 5分钟 / 15分钟 / 30分钟 / 1小时 / 3小时 / 6小时 / 12小时 / 1天
- ✅ 切换方式：按顺序 / 随机（随机不会连续重复同一张）
- ✅ 长按拖拽排序：长按任意壁纸进入抖动编辑态，拖动时其余壁纸实时让位/补位，松手即保存顺序
- ✅ 一键使用：缩略图下方「使用」按钮，点击立即把该张设为当前壁纸（无弹窗、不跳转）
- ✅ 手动裁剪：点击缩略图进入预览页，双指捏合缩放 / 拖动调整裁剪位置，竖图横用不再切掉主体
- ✅ 应用目标：仅桌面（不修改锁屏壁纸）
- ✅ 「立即换一张」手动切换
- ✅ 开机自启：重启后自动恢复轮换
- ✅ 保活：精确闹钟授权、电池优化白名单申请
- ✅ 深色模式 / Material 3 动态取色

## 安装

直接安装 `app/build/outputs/apk/debug/app-debug-v<版本号>.apk`（例如 `app-debug-v1.4.apk`，调试签名，可覆盖安装升级）。

> 安装时若提示「禁止安装未知来源应用」，按提示允许本浏览器/文件管理器安装应用即可。

## 首次使用（重要，ColorOS 请务必做第 1~3 步）

1. **自启动**：设置 → 应用 → 壁纸轮播 → 自启动 → 允许
2. **电池**：设置 → 电池 → 更多电池设置/应用速冻，找到「壁纸轮播」→ 不优化 / 允许后台运行；
   或直接在 App 内「后台保活」卡片点 **去设置**（申请忽略电池优化）
3. **锁定后台**：最近任务里下拉「壁纸轮播」卡片，出现锁图标（防止一键清理）
4. **精确闹钟**：App 内「后台保活」卡片点 **去授权**（保证间隔准确，息屏也按时换）

之后：打开 App → 添加几张壁纸 → 打开「自动轮换」开关 → 选间隔 → 完成，回桌面等着看效果即可。

## 常见问题

| 现象 | 解决 |
| --- | --- |
| 间隔偶尔不对/延迟 | 去「后台保活」授权精确闹钟；Doze 深度休眠会顺延到维护窗口 |
| 重启后不换了 | 确认自启动权限已开（BootReceiver 需要它才能收到开机广播） |
| 1 分钟间隔偶尔不生效 | 非 Doze 情况下系统闹钟最小粒度约 1 分钟，属正常 |

## 技术说明

- Kotlin + Jetpack Compose（Material 3），minSdk 29 / targetSdk 35
- 换壁纸：`WallpaperManager.setBitmap()`（FLAG_SYSTEM，仅桌面），**无需 root**
- 定时：`AlarmManager.setExactAndAllowWhileIdle()` 逐次续排（无精确闹钟权限自动降级）
- 壁纸尺寸：严格等于屏幕分辨率（自然方向，与当前旋转无关），系统端 scale 恒为 1（不会放大数倍/靠左）。**注意**：不能用 `WallpaperManager.getDesiredMinimumWidth()`，ColorOS 会返回约 2 倍屏宽，按它出图会导致画面被居中裁剪放大一倍
- 图片复制到应用私有目录 `filesDir/wallpapers/`，列表顺序存于 SharedPreferences
- 手动裁剪：预览页用 `detectTransformGestures` 做捏合缩放 + 平移，视图框比例 = 屏幕比例（所见即所得）；确认时把可见区域换算成**归一化矩形**（0..1，相对源图）存入 `crop_<文件名>`，与图片分辨率无关

## 构建

```bash
# Android Studio 直接打开本目录，或命令行：
./gradlew assembleDebug
```

Gradle wrapper 已生成；国内网络可在 `gradle/wrapper/gradle-wrapper.properties` 中把
`services.gradle.org` 换成 `https://mirrors.cloud.tencent.com/gradle/` 前缀加速。

### 版本号规则

- `versionName`：真实语义化版本（如 `1.5.0`），发版只改 `appMajor` / `appMinor` / `appPatch` 三个数字。
- `versionCode`：由上面三个数字自动算出 `30000000 + major*10000 + minor*100 + patch`，单调递增，用户看不到。基数 3000 万是为了高于历史误用的日期版本号，避免被判成降级安装。
- 产物文件名：`app-debug-v<versionName>.apk`，随版本自动变化。

> **每次出包请递增 `appPatch`（哪怕一天发两次）。** 文件名必须变：若一直叫同一个名字，
> 通过 QQ/微信传到手机时会被当成同一个文件、直接打开旧包，安装器就会报
> 「已安装相同或更高版本」，看起来像是版本号错了，实际是文件没换。
